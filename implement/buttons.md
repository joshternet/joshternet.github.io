# Joshternet buttons

Remember the little buttons people used to put on their websites? Joshternet has
one of those, too. It's a small way to show that your website is part of the
network and give visitors another path into the independent web.

Small web buttons have been helping people discover interesting websites for
decades. This one continues that tradition with a little Joshternet personality.
The button checks the public Joshternet registry and displays the current listing
state for your website. Add it if you like. It isn't required to participate, and
your website remains entirely yours.

Want the button on your site? Use it. Prefer not to include an external script?
That's fine, too. The button is an optional way to show your connection to the
Joshternet, not another requirement for joining. Participation still means
publishing a valid `/.well-known/josh`; start with the
[join guide]({{ '/join/' | relative_url }}) if you have not done that yet.

## Install

Add the following script wherever you want the button to appear. It detects the
current website's origin with `window.location.origin`, so you don't need to put
your domain into the snippet.

{% if jekyll.environment == "development" %}

```html
<script async src="http://127.0.0.1:8790/embed/joshternet-button.js"></script>
```

Start the local stack with `npm run dev` (Jekyll plus this Worker on `:8790`) so
the development embed works.

{% else %}

```html
<script async src="https://joshternet.org/embed/joshternet-button.js"></script>
```

{% endif %}

After JoshBot verifies a declaration and the registry updates, the button changes
automatically. You do not need to edit the embed again.

The button is generated by the embed script as inline SVG after a registry check,
rather than served as a standalone image. Keep the script in place if you want it
to reflect the registry's current information. Do not host or hotlink a
standalone button image. Embed version currently shipped: `20261004`.

## What the button shows

The faces below exist only inside that same embed, after a successful lookup:

- **Verified Josh** — The public registry lists this origin with a valid
  declaration affirming Josh identity.
- **Verified Non-Josh** — The registry lists this origin with a valid declaration
  declining Josh identity.
- **Undeclared** — The registry lists this origin as participating without a Josh
  identity declaration.
- **Join the Joshternet** — The registry lookup succeeded and the site is **not
  currently listed** in the public registry. That is not the same as a failed or
  invalid declaration; a site can already participate and still show this face
  until JoshBot lists it. Join reflects the registry's current knowledge, not a
  definitive statement that the website has not published a valid declaration.

Verified means JoshBot has checked the website's published declaration for its
registry. It doesn't mean Joshternet has verified the person's legal identity,
reviewed everything on the site, or endorsed its contents.

If Joshternet's registry can't be reached, the button stays out of the way rather
than guessing. The embed renders nothing. A temporary Joshternet outage must
never make an existing member look like they left, and an unavailable registry
must never be treated as Join.

## Content Security Policy

If your website uses a restrictive Content Security Policy, you may need to allow
the Joshternet script and its registry request. The relevant directives are:

```text
script-src https://joshternet.org
connect-src https://joshternet.org
```

The graphic is inline SVG, so the embed does not need `img-src`. Do not disable
CSP or open every third-party origin solely to display this optional button.

## Accessibility

The button includes an accessible name describing its current state. Each face
ships with state-specific alternative text, for example “Verified Josh,
Joshternet site” or “Join the Joshternet”. The surrounding link has a matching
accessible name. Width and height are always 88 and 31 so the page does not shift
while it loads.

## Advanced: machine-readable state

Want to see the data behind the button? The endpoint returns the registry-backed
state and the information the embed uses to build its link and accessible label:

```text
GET https://joshternet.org/api/button-state?origin=https://joshua.example
```

Returns JSON for the registry-backed state, including `state`, `href`, `alt`,
`linkLabel`, `ok`, `origin`, and `member`. It does not include a file URL for a
standalone image. Registry failures return `state: "unavailable"` and must not be
treated as Join. This endpoint does not define the core Joshternet participation
protocol.
