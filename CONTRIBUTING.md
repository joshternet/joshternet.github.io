# Contributing to Joshternet

Thank you for helping with [joshternet.org](https://joshternet.org/). You do not need to be named Josh to contribute.

## Where to start

1. Read the project overview in [README.md](README.md).
2. Set up a local environment with [docs/development.md](docs/development.md).
3. Browse [open issues](https://github.com/joshternet/joshternet.github.io/issues) or start a discussion before large changes.

## Developer documentation

| Guide | Contents |
| --- | --- |
| [docs/development.md](docs/development.md) | Local setup, commands, tests, fixtures, and coding conventions |
| [docs/data-pipeline.md](docs/data-pipeline.md) | System boundaries and processing principles |
| [docs/operations.md](docs/operations.md) | Release practices and recovery responsibilities |

Protocol changes belong in [joshternet/spec](https://github.com/joshternet/spec), not as undocumented website behavior.

## Pull requests

Work in a focused branch. Include tests and documentation updates when behavior changes. Do not commit secrets or hand-edited network observations. See [docs/operations.md](docs/operations.md) for release ownership boundaries.
